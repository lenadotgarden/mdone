# Deviations from the Things spec

Each deviation is attached to the spec section concerned. Status: `TODO` = to do, `stopgap` = temporary solution in place.

## First Mac slice (window, sidebar, lists, editor, commands)

Code written without a compiler, to be validated by the macOS CI then on a Mac. Files in `mDone/Platform/macOS/Things*`, shortcut table and Quick Find engine in `mDone/Features/Things/` (pure, tested).

| Spec | Deviation | Status |
|-|-|-|
| Interface | `@AppStorage("thingsUIEnabled")` (true by default) chooses `ThingsMacRootView` or `MacContentView` on Mac too. The "Interface Things" setting is visible on Mac. The Mac screen tests (`MacScreenshotTests`) pass `-thingsUIEnabled NO` to stay on the old window. With the old interface, the Things menus are greyed out but the File menu loses "New Window" (Cmd N is taken by the replaced `newItem` group). | stopgap |
| 04 section 1 (window) | A single detail panel, no inspector. No Trash, no special lists (Tomorrow, Deadlines, Repeating, All Projects, Logged Projects), no new window (Ctrl-Cmd-N), no Cmd-click to open in a window, no toolbar hiding, no Cmd-click on an Area chevron to fold everything. Share button absent. | TODO |
| 04 section 1 (sidebar) | Counters for Inbox and Today only, hidden at zero. The full tree is shown: loose projects, then each Area with all its descendants (any depth), with a disclosure chevron on every row that has children (always visible, fold state persisted per project id in `AppState.collapsedProjectIDs`, everything open by default, Cmd-click folds all, Expand All and Collapse All in the bottom menu). A root project with sub-projects is an Area even without the `things:area` marker; a project that holds sub-projects is never hidden, even when it was guessed to be the Inbox. Archived projects are hidden, their live children surface at the root. Trash absent. Drag a to-do onto a project, Area, Inbox, Today or Someday; drag a project onto the middle of a row to nest it, onto the top or bottom edge of a row to place it between siblings (position written through `PUT /projects/{id}`, loose projects and Areas are never mixed at the top level). Move Project... in the context menu and Shift-Cmd-M. | stopgap |
| 04 section 3 (open to-do) | `ThingsMacTodoEditor` is written from scratch (no reuse of `TaskDetailSheet`, which is a form). It saves through `AppState.updateTask`. Notes are edited as plain text (an HTML description from the web stays HTML), without Markdown. No Repeat, no Share, no reminder, no Find in Text, no Opt-Cmd-Return to open a link. Double-click or Return opens; Esc or Cmd-Return saves and closes; selecting another row closes (and saves). A click on the title that is already selected does not open it. | TODO |
| 04 section 4 (popovers) | When (Cmd S): header "When" that becomes a text field (natural language through `ThingsNaturalLanguage`, so "tomorrow" or "sept 25" work), Today and This Evening with a checkmark for the current value, a Monday first month grid (`ThingsCalendarGrid`, today marked with a star, chevrons change the month, hover and keyboard highlight), Someday, Add Reminder (time input, stored as an absolute reminder, a to-do without a When gets Today) and a full width Clear button. Arrows move over the grid, Return picks, Esc closes. Deadline (Shift Cmd D): flag field "Deadline", the same grid with today filled blue, Clear. Both hang on the selected row, or on the open card. They are written from the description of the Things popovers: the captures mac-dark-06 to 10 were not in the repository, so spacing and colours are ESTIMATED. Past days in the When grid read as Today. Tags: search, checkboxes, creation. Move: filter, Inbox, whole project tree; for a project or an Area: No Area (root) or any project except itself and its descendants. No headings or inactive projects. Shift-Cmd-M with no to-do selected opens the popover in the sidebar, anchored on the row of the project or Area on screen (the sidebar must be visible). | stopgap |
| 04 section 5 (Quick Entry) | Floating `NSPanel` (title, notes, fixed Inbox destination). Ctrl-Space opens it through the menu when the app is active. The global shortcut uses `NSEvent.addGlobalMonitorForEvents`, installed only if `AXIsProcessTrusted()`; the "Enable Global Quick Entry..." menu asks for Accessibility access. A global monitor cannot consume the key: macOS may also switch the input source. No Autofill, no tags, no When or Deadline in the panel, no shortcut setting. | stopgap |
| 04 section 6 (Quick Find) | Overlay card opened by Cmd-F, the magnifier or Type Travel: lists, to-dos, projects and Areas, tags. A chosen tag stays in the field and shows the to-dos that carry it; Delete on an empty field leaves the tag. No "Continue Search" (notes, checklists, Logbook), no Cmd-Return in a new window, no headings in the results. | TODO |
| 04 section 11 / 05 (selection) | Single selection. Arrows, Opt arrows (first, last), Return (open), Space, Delete, Backspace and Cmd Backspace are handled by the key handler of the list, not by the menu (a key without Cmd or Ctrl in a menu would fire while typing). Delete removes the selected to-do at once, no confirmation (Things relies on undo); Vikunja cannot undelete, so Undo creates the to-do again with a new id (see the Undo row below). Holding the key does not run through the list (first press only). Space adds an empty to-do right below the selection (same project, When and section, positioned with `moveTask(toPosition:)`), or at the top of the project when only a project is selected; the new to-do is typed in the inline row, not in an open card as in Things. `thingsMacSpaceKey(model:)` extends Space to the rest of the window once the root view applies it (WIRING-AGENT-B2.md). Opt-click on the box cancels. Esc clears the selection. No Shift arrows, Cmd-A or multi-selection. | TODO |
| 05 (move) | Cmd Up and Cmd Down move the selected to-do one place, Opt Cmd Up and Opt Cmd Down send it to the top or the bottom of its section (spec 05). They need the list view of the project (`AppState.moveTask(toPosition:)`) and a manual order, and are ignored with no selection, in a read-only section (Logbook), during a drag, or while the previous move is still saving. System drag and drop (`onDrag`, `DropDelegate`) reorders inside a section with a gap that opens (`ThingsMotion.reorder` spring) and also moves between sections where that makes sense (Today and This Evening, the Someday group of a project), see `08-drag-and-drop.md`. The drop itself is not animated: the optimistic order, the end of the gap and the reappearing source row change in one transaction, so the dragged row lands exactly in the gap with no second reflow or fade, and the server refresh does not animate again (a failed save slides back). No guaranteed auto-scroll, no multi-selection, no deadline or date by drop (Upcoming), no drop in an absent section. Accessibility actions and the context menu offer Move Up, Move Down and Move to <section>. Shift-Cmd-Y ("Move completed to Logbook"): a finished to-do enters the Logbook at once. | stopgap |
| 05 (navigation) | Cmd-Left (back) conflicts with the cursor in text fields: the previous and next buttons of the toolbar exist, without a shortcut. Shift-Cmd-O (navigation popover), Cmd-L, Cmd-Right, Ctrl-Opt-Cmd-arrows: absent. | TODO |
| 05 (creation) | Shift-Cmd-N (New Heading): the menu entry exists, disabled, as long as headings are not read (see above, 02 section 10). Opt-Shift-Cmd-N and multi-line Cmd-V: absent. Cmd-D duplicates through `createTask` (title, notes, deadline, priority, tags, start date), without the checklist. | TODO |
| 05 (dates, tags) | Cmd-S/T/E/R/O, Ctrl-] and [ (day, week), Shift-Cmd-D, Ctrl-. and , (day, week), Shift-Cmd-T are done. Shift-Cmd-R (Repeat) is absent. Cmd-R (Anytime) removes the When (project to-do: Anytime list). Ctrl-Cmd-T (Tags window), tag shortcuts, filter by tag (Ctrl-Esc): absent. | TODO |
| 04 section 6 (Type Travel) | Done on Mac by an `onKeyPress` at the root, with no combination required. The first keys typed while the card is opening may be lost. Quick Find is an overlay card, not a window. No Type Travel on iPhone. | stopgap |
| 04 section 5 and 02 (natural language) | Natural language partly replaces the When, Deadline and tag buttons of Quick Entry. Syntax: see WIRING-AGENT3.md. Unknown tags and projects are not created. A reminder uses the time typed on the day of the When. Active by default (see the Transverse section). | stopgap |
| 07 section 5 (sub-tasks) | Sub-task hiding no longer hides every task that has a parent (`ThingsChecklist.isChecklistItem`). A sub-task stays hidden only if it is a simple step: same project as its parent, no start date, no deadline, no label, and not open under a finished parent. Otherwise it is a real to-do and it appears in the lists (otherwise Vikunja's real sub-tasks disappeared from everywhere). | stopgap |
| Performance (reading the lists) | `AppState.thingsCache` (`ThingsListsCache`) memoizes lists, counters and progress per project, key: `tasksRevision`, Inbox project, day, calendar. The project tree is memoized by `ThingsProjectTreeMemo`. A `refreshAll` in progress is shared, and returning to the foreground only relaunches a `refreshAll` 30 s after the last success. | stopgap |
| 04 section 2 (Today, events) | The calendar events box is done. It only appears if EventKit access is already granted: the list never asks for permission. | stopgap |

## Undo, completion and drop animation (Mac list)

Code written without a compiler, to be validated by the macOS CI and on a Mac.

| Spec | Deviation | Status |
|-|-|-|
| 05 (Cmd Z, Shift Cmd Z) | Edit > Undo and Redo name the step ("Undo Complete To-Do"). History: `ThingsUndoStack` (pure, `Features/Things`, tested), depth 100, rapid edits with the same key within 1.5 s merge into one step (Ctrl ] pressed five times, a burst of reorders), cleared on logout (`ThingsMacModel.clearUndoHistory`, and every undo and record checks `isAuthenticated`). Covered: complete and reopen, cancel, delete, create, duplicate, move to a project or Area, move of a project, reorder and move between sections, When, Deadline, reminder, title and notes of the card, tags, checklist items (add, tick, rename, delete). Vikunja cannot undelete: Undo Delete creates the to-do again (title, notes, deadline, start date, tags including the This Evening and Someday labels, priority, project, repeat, checklist, done state) and the id changes; older steps follow it through an alias table. The recreated to-do goes where the server puts a new task, not back at its old position; comments, attachments, reminders, assignees and the creation date are lost. A focused text field keeps its own undo (the menu action forwards `undo:` to it when a text view is first responder; the items stay enabled while a card, the new to-do row, Quick Find or a sheet is open). Without a Things window (classic interface) the items forward to the responder chain. Not covered: Opt-click cancel through other paths, sidebar renames, New Project and Area creation. | stopgap |
| 06 section 2 (completion, Mac) | Ticking the box (click, Cmd K, the card checkbox) fills the box and draws the checkmark in 0.25 s (`ThingsMotion.checkDraw`, a `trim` of a path), the title greys and a strike line grows over it (0.2 s, an overlay instead of `strikethrough`, which cannot animate), the row stays 1 s (`completionRemovalDelay`) and then collapses (`rowRemoval`). A second tick during that second cancels. With Reduce Motion every step is immediate. The iPhone row keeps the text strikethrough. | stopgap |

## Transverse (localisation, preferences, structure)

| Spec | Deviation | Status |
|-|-|-|
| Localisation | French added in `mDone/Localizable.xcstrings` (and `mDoneWidgets` for the shared keys) for all the text of the Things screens. Choice: the list names stay in English, they are the brand vocabulary of Things (Inbox, Today, This Evening, Upcoming, Anytime, Someday, Logbook), everything else is translated. The day words (Tomorrow, Yesterday) and the status words are translated. Terms chosen: Area = Zone, Deadline = Échéance, When = Quand, Heading = En-tête, Quick Find = Recherche rapide, Quick Entry = Saisie rapide. The rest of the app (screens from before the fork) has no French: only the Things text is covered. `scripts/check-things-localization.py` (CI) fails if a Things text has no French. | stopgap |",
| 04 section 5 (preference) | Natural language ("Smart parsing" in Settings) is enabled by default everywhere: `SmartParsingPreference.defaultValue` is `true`, which also applies to the old add bar, Siri and Shortcuts. A value already chosen by the user is kept. `ThingsNaturalLanguagePreference` is removed. | stopgap |
| Structure | `ThingsMagicPlusButton` is in `DesignSystem/Components/Things` (it was in `Platform/iOS`, an upper layer, while `Features/Things` uses it). `scripts/check-layering.sh` also checks that Features and DesignSystem do not reference the `ThingsMac*` types or Quick Entry, and that Core and Domain do not reference the Things ViewModels. | stopgap |
